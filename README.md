# 💰 お給料明細

夫専用の、写真から記録するお給料ノート。2026年9月30日に完全な新規プロジェクトとして作成。以前の給与明細アプリのコードは参照・再利用していません。

## 使い方

「給与明細を撮る」または「写真から選ぶ」→ 年月と4項目の金額を確認 → 必要なら修正・メモ入力 →「確認して保存」。写真なしの手入力もできます。読み取り後の自動保存はしません。

過去の明細は1件ずつ表示・編集・削除できます。削除前に確認します。グラフは同じ月の振込支給額を合計して表示します。バックアップは写真を含むJSONファイルです。

## プライバシーと費用

- 給与・写真・メモはこのアプリ固有のIndexedDBに保存。端末やブラウザ間の自動共有はありません。
- OCR、HEIC変換、縮小、グラフはブラウザ内処理。外部OCR API、APIキー、有料クラウド、解析・広告は不使用。
- 必要なOSSライブラリと日本語・英語データを同梱。写真は外部へ送信しません。
- アプリの配信時にはGitHub Pagesへ通常のファイル取得通信が発生します。写真を送信する通信はありません。
- 端末のデータ削除・故障・ブラウザによるデータ整理で記録が失われることがあるため、定期的にバックアップしてください。
- バックアップは暗号化していません。給与情報と画像が含まれるので本人が安全に保管してください。

## 安定性

- index.htmlにトップ画面を直接記述。起動時にOCR・HEIC・グラフ用コードを待ちません。
- OCRは写真を選択したときだけ別の処理画面とWorkerで実行。210秒の上限・中止ボタン付き。
- 保存用画像とは別に用紙部分を自動で切り出し、長辺2600〜3400pxの読み取り用画像を作ります。明るさ・局所コントラスト・罫線を補正し、全体で不足した場合だけ重なり付きの4区画を拡大して再確認します。
- 表の見出しと離れた金額を位置で結び、支給合計−控除合計と振込支給額の関係も候補選びに使用します。
- HEICはブラウザの標準読み込みを先に試し、必要な場合だけ変換部品を別画面で読み込みます。変換上限45秒。
- heic2any内のコード生成処理に必要な `unsafe-eval` は、HEIC専用の処理画面だけで許可。メイン画面・OCR画面には許可せず、HEIC処理画面からのネットワーク接続も禁止。
- 保存画像は長辺2200px以下のJPEG（品質0.86）。再エンコードにより元画像のEXIF位置情報などを持ち越しません。
- 読み取り中の手入力値は上書きしません。失敗しても手入力できます。
- 復元は形式・年月・数値・画像形式などを全件検証してから、一つの保存処理でまとめて追加。同じ年月・4金額・メモの組み合わせは重複追加しません（画像だけの違いは追加しません）。内容が異なる記録は元を残して追加します。

## 制限

- OCRは読み違いがあります。表・小さい文字・離れた金額への補助処理はありますが、強い傾き・反射・影・特殊な書体では空欄や誤りになることがあります。必ず原本と照合してください。
- iPhone 15 Pro Max実機でのカメラ撮影・ホーム画面アイコン表示は未確認。Mac ChromeとSafari方式のWebKitで自動検証済みです。
- HEIC/HEIFのすべての種類は保証できません。失敗時はJPEGや手入力で続行できます。
- 初回OCRの部品は約数MBです。初回や低速回線では時間がかかることがあります。オフラインでの起動は保証しません。
- 入力は0〜9,999,999,999円の整数、年月1900〜2200年、メモ3000文字まで。画像50MBまで、復元ファイル150MB・10,000件まで。
- ブラウザ内の保存容量には端末ごとの上限があります。

## ファイル

`index.html` が画面、`style.css` が見た目、`app.js` が保存と操作。`reader.js` / `processing-frame.*` / `heic-frame.html` が画像処理、`amounts.js` が金額抽出、`graph.js` がグラフ。`assets/` が専用アイコン、`vendor/` が無料の処理部品です。

GitHub Pagesのmain / rootで配信可能。ビルドやサーバー処理は不要です。ローカルの `tests/` は公開しません。
